# SpendWise

Offline-First Smart Expense & Budget Analytics Manager built with Flutter, SQLite & REST API.

## Features
- **Offline-First Persistence**: Powered by SQLite for zero-latency, private financial tracking.
- **Visual Analytics**: Interactive category breakdown and spending charts with `fl_chart`.
- **Multi-Currency Support**: Real-time exchange rates via REST API.
- **Budget Thresholds**: Instant alerts when exceeding 80% and 100% of spending limits.
- **Statement Export**: 1-tap export of financial logs to CSV.

## Tech Stack
- **Framework**: Flutter & Dart
- **State Management**: Provider
- **Storage**: SQLite (`sqflite`), SharedPreferences
- **Charts**: `fl_chart`
- **Networking**: `http` REST API
